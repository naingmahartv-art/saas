Get public URL for saas-platform

Step 1 — Terminal 1: Start app

cd ~/Documents/saas-platform
npm run dev

Wait until you see "Ready on http://localhost:3000"

Step 2 — Terminal 2: Start tunnel

ngrok http 3000

ngrok shows your URL like: https://xxxx.ngrok-free.app

If ngrok not installed

# Install with Homebrew:
brew install ngrok

# OR use without installing:
npx localtunnel --port 3000
